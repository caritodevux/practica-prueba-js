# Ejercicios practicos para practucar Javascript
Hay 5 ejercicios en este repositorio:
1. **Ejercicio carrito**: Establece 3 productos con nombre y precio. Muestra estos items y hace el calculo del total de la suma de los 3 productos con un descuento aplicado.
2. **Ejercicios CRUD**: Lista de tareas, donde se puede agregar, revisar y eliminar tareas. No se implemento la edición de entradas.
3. **Ejercicio rápido**: Practica con un switch que entrega una mensaje de "acceso correcto" a las persona mayores de 18 años. Tambien se contemplo el caso de no ingresar ningún dato.
4. **Ejercicio registro**: Simula el registro de nuevos empleados ingresando tres campos: nombre, edad y email. Revisa si los carcateres ingresado son correcto, casos en que no se ingresan datos. Tambien limpia el registro una vez realizada un registro correcto, para no eliminar la información de manera manual.
5. **Ejercicio tipo veterinaria**: Ejercicio integrador de los distintos ejercicios anteriores.

Este ejercicio fue creado con inteligencia artificial, dandole como base las guias y ejercicios desarrolladas en clase, con un enfoque prinpiante.
